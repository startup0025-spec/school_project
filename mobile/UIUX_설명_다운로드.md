# 잔물결 UI/UX 설명

## 1. 전체 콘셉트

- **잔물결**은 물과 자연을 매개로, 사용자의 일상 속 고요함을 틈틈이 끌어주는 앱입니다.
- 기록, 추천, 알림 기능이 사용자를 압박하지 않고, **주변 환경에 따라 조용히 반응하는 동반자**처럼 느껴지도록 설계했습니다.
- 핵심 키워드: **잔잔함, 반응성, 비압박, 감각적 피드백, 안전한 가드**.

---

## 2. 화면 구조

### 하단 탭 5개

| 탭 | 이름 | 역할 |
|---|---|---|
| 홈 | 잔물결 | 오늘 나의 상태를 물결 오브로 확인 |
| 소리 | 소리 | 주변 물소리를 파형으로 시각화해서 듣는 느낌 |
| 물길 | 물길 | 검색 없이 한 곳만 조용히 추천 |
| 기록 | 기록 | 자동으로 쌓이는 고요했던 순간 |
| 안전 | 안전 | 위험 구역에서만 살짝 경계 |

- 알림 기록은 **홈 상단 벨 아이콘**으로 이동. 탭은 5개로 유지.

---

## 3. 화면별 UX 느낌

### 3.1 홈 (Home)

- **물결 오브**가 중앙에 크게 배치되어, 사용자가 현재 얼마나 흔들리고 있는지를 직관적으로 느끼게 합니다.
- 상태: 잔잔함 → 걷는 중 → 바쁨 → 위험. 오브의 속도와 흔들림이 점점 격해집니다.
- 오브 아래에 짧은 문구로 현재 상태를 부드럽게 설명합니다.
- 하단 세그먼트 컨트롤로, 센서가 없는 프로토타입에서도 상태를 직접 바꿔보며 반응을 확인할 수 있습니다.
- 상단 벨 아이콘 → 알림 기록 화면.

### 3.2 소리 (Sound)

- **소리 흐름을 파형으로 시각화**. 흐르는 상태, 멈춘 상태, 위험 상태(잡음/글리치)를 눈으로 구분합니다.
- 물소리 종류(시냇물 / 강물 / 바다)를 칩 버튼으로 선택하면 설명과 파형 느낌이 따라 바뀝니다.
- **"화면을 꺼도 소리는 계속 흘러요"** 카드로, 앱이 적극적으로 요구하지 않고 배경에서 동반한다는 느낌을 줍니다.
- 플레이/일시정지 버튼으로 직접 소리 흐름을 멈춰볼 수 있습니다.

### 3.3 물길 (Map)

- **검색 바 없이**, 오늘 가장 조용한 물길을 **단 한 곳**만 카드로 보여줍니다.
- 지도 위에 핀이 부드럽게 맥동하며 추천 지점을 강조합니다.
- 카드에는 장소 이름, 짧은 설명, 도보 시간만 들어 있습니다.
- "다른 물길 보기"로 후보를 번갈아 볼 수 있지만, 한 번에 하나만 보여주는 것이 핵심입니다.

### 3.4 기록 (Diary)

- 사용자가 직접 사진이나 텍스트를 입력하지 않습니다.
- 조용히 머문 시간이 **자동으로 타임라인**으로 쌓입니다.
- **"지금처럼 머문 10분 기록하기"** 버튼으로, 고요한 상태에서만 직접 기록을 시뮬레이션할 수 있습니다.
- 각 기록은 "언제, 어디서, 얼마나"만 남깁니다. 과하지 않게.
- 기록이 없을 때는 비어있음 상태를 부드럽게 표시합니다.

### 3.5 안전 (Safety)

- 평소에는 **조용한 가드 상태**. 수치가 없어도 "지켜보고 있어요"라는 느낌을 전달합니다.
- 위험 구역으로 전환하면, 파형이 잡음/글리치로 바뀌고 부드러운 경고 배너가 나타납니다.
- "다른 곳 보기" 액션으로 물길 화면으로 자연스럽게 유도합니다.
- 안전/위험은 세그먼트 컨트롤로 직접 전환해볼 수 있습니다.

### 3.6 알림 기록 (Notifications)

- 지금까지 받았던 **한 줄 알림**들을 타임라인처럼 보여줍니다.
- 푸시가 아닌, 부드러운 한 마디의 느낌을 유지합니다.

## 4. 공통 UX 느낌

### 4.1 정보 밀도

- 화면당 **핵심 1개 + 부가 1~2개**만 보여줍니다.
- 긴 설명 없이 시각적 요소(오브, 파형, 지도 핀)가 대신 말합니다.

### 4.2 상호작용

- 탭 전환, 상태 전환, 버튼 누름에 **햅틱 피드백**을 넣어 물리적인 느낌을 줍니다.
- 세그먼트 컨트롤과 칩 버튼은 한눈에 상태를 파악할 수 있게 합니다.

### 4.3 언어 톤

- 반말 + 평서문. 명령하거나 조바심 내지 않습니다.
- 예: "지금 해운대는 너무 붐벼요. 그냥 집 근처 시냇가에서 발이나 담그는 게 어때요?"
- 예: "오늘은 유독 조용하네요. 창문 좀 열어두는 것도 좋을 것 같아요."

### 4.4 프로토타입 시뮬레이션 방식

- 실제 GPS, 센서, DB, 백엔드가 없으므로, 사용자가 직접 상태를 조작하는 **데모 컨트롤**을 화면에 노출했습니다.
- 홈: "고요 / 걷는 중 / 바쁘게"
- 소리: "시냇물 / 강물 / 바다"
- 안전: "안전 / 위험"
- 실제 서비스에서는 이 컨트롤이 숨겨지고, 실제 센서/위치 데이터가 대신합니다.

---

## 5. 요약

잔물결은 **"앱이 사용자를 관리하지 않고, 사용자의 주변과 함께 조용히 반응한다"**는 느낌을 UI/UX로 표현한 프로토타입입니다. 물결, 파형, 한 줄 메시지, 단일 핀, 자동 기록, 부드러운 경고를 통해 기능이 사용자의 일상 위에 가볍게 얹혀지도록 설계했습니다.
